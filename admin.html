Photo Gallery

How to add photos to the website

  1. Click Open Website Folder below and select the docs folder inside this project (the one with index.html directly inside it — not the top-level project folder).
  2. Type or pick a category (for example "Farm Lands" or "Plots & Lands"), choose one or more photos, and click Add Photos. They save immediately — no separate Save step.
  3. Publish the change the same way you normally do (for example, GitHub Desktop → Commit → Push). The photos will appear on the live site a minute or two after that.

Photos show on the Gallery page under whichever category you chose, and visitors can filter by category.

This section needs Chrome or Edge — other browsers can't save photo files directly to the project.

Videos

How to add a YouTube video to the website

  1. Click Open videos.json below and select the videos.json file — it's inside docs/data/ in this project.
  2. Paste a YouTube video link into the box and click Add Video. The title fills in automatically.
  3. Click Save.
  4. Publish the change the same way you normally do (for example, GitHub Desktop → Commit → Push). The video will appear on the live site a minute or two after that.

To remove a video, click Remove under it, then Save and publish the same way.
